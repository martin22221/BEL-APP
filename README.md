# BEL-APP

Уеб приложение за подготовка за матура по български език и литература: тестове по теми, пробна матура с таймер, резултати с обяснения и статистика по слаби теми.

Учебен проект по софтуерно инженерство.

## Технологии

| Част | Технологии |
|---|---|
| Фронтенд | React 19, Vite, React Router |
| Бекенд | Node.js, Express 5 |
| База данни | PostgreSQL 16, Prisma ORM |
| Тестове | Vitest, Supertest |

## Пускане локално

Нужни са [Node.js 20+](https://nodejs.org) и [Docker Desktop](https://www.docker.com/products/docker-desktop/) (за базата).

**1. База данни** (от главната папка):

```bash
docker compose up -d
```

**2. Бекенд:**

```bash
cd server
cp .env.example .env        # в Windows: copy .env.example .env
npm install
npx prisma migrate dev      # създава таблиците
npm run db:seed             # теми и примерни въпроси
npm run dev                 # http://localhost:4000
```

Проверка: отворете http://localhost:4000/api/topics

**3. Фронтенд** (в нов терминал):

```bash
cd client
npm install
npm run dev                 # http://localhost:5173
```

Фронтендът пренасочва заявките към `/api` към бекенда, затова няма нужда да пишете пълния адрес.

## Полезни команди (в `server/`)

| Команда | Какво прави |
|---|---|
| `npm run dev` | Пуска сървъра и го рестартира при промяна |
| `npm test` | Пуска тестовете (API тестовете искат пусната база със seed) |
| `npm run db:migrate` | Нова миграция след промяна в `schema.prisma` |
| `npm run db:seed` | Добавя въпросите от `prisma/data` (без да дублира) |
| `npm run db:reset` | Изтрива базата и я създава наново |
| `npm run db:studio` | Отваря Prisma Studio за преглед на данните |

## Добавяне на въпроси

Въпросите са в `server/prisma/data/questions.json`:

```json
{
  "topic": "pravopis",
  "text": "Коя дума е написана правилно?",
  "answers": ["безсмислен", "бесмислен", "бессмислен", "безсмисслен"],
  "correct": 0,
  "explanation": "Представката без- запазва буквата „з“..."
}
```

- `topic` е `slug` от `topics.json`
- `correct` е номерът на верния отговор, като броенето започва от 0
- Отговорите се разбъркват при показване, затова верният може винаги да е първи

След промяна пуснете `npm run db:seed`.
